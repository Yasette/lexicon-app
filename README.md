# Lexicon (app)

The public app. A cumulative vocabulary set — grouped by frequency and
difficulty, **not** by week — with an onboarding walkthrough, SAT practice,
and the lesson sheets.

Seeded as a full copy of the personal site at `Yasette/lexicon`, which stays
private-facing: that one is organised by Yasemin's own study weeks and is for
her and her friends. The two diverge from here; this repo is the one that
goes to the App Store and Play Store.

| | `Yasette/lexicon` | `Yasette/lexicon-app` |
|---|---|---|
| audience | me + friends | everybody |
| grouping | study weeks (W1–W21) | frequency / difficulty |
| onboarding | none | walkthrough on first run |
| published | GitHub Pages | App Store + Play Store |

Words, quiz bank, transitions data and lesson sheets all live inside
`index.html`, same as the original.
